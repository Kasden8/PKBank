# PKBank — Attribution & Credits

PKBank is a PC (Windows) port of **[PKForge](https://github.com/sofianeelhor/PKForge)** (Android) by **sofianeelhor**,
built on top of the **[PKHeX](https://github.com/kwsch/PKHeX)** engine by **Kaphotics** and all its contributors.
This project would not exist without either project. Both are GPLv3-or-later.

This document credits every third-party asset and notes the license of each part.
Pokémon and Pokémon character names are trademarks of Nintendo, Creatures Inc., and GAME FREAK Inc.
PKBank is not affiliated with Nintendo, Creatures Inc., GAME FREAK Inc., or The Pokémon Company.

## Deliberately **not** redistributed

| Asset | Why |
|---|---|
| SteamGridDB game art (`GameArt/`, `GameHero/`, `GameLogo/`, ~24 MB) | Community-submitted artwork; license unclear and not ours to redistribute. The PC client uses colored tiles / game-icons instead. |
| PMDCollab SpriteCollab (`pmdcollab.org`) | CC BY-NC 4.0. If the Poképark fetches animated sprites, it does so **at runtime** with on-screen credit, never bundled. |
| Nintendo's game artwork, ROMs, and save files | Never distributed. |

## Non-commercial reminder

Because a few bundled assets are CC BY-NC(-SA) (NDS12 font; Bad Apple!! tribute),
**PKBank must stay free and non-commercial** as distributed. Do not sell builds.

## Reporting attribution mistakes

If any credit is missing, wrong, or any asset should not be here, please open an issue and it will be corrected or removed promptly.
